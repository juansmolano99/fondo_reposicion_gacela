# Fondo de Reposición Gacela

Aplicación web para la gestión del fondo de reposición de vehículos del Grupo Gacela.

## Características principales

- Consulta de vehículos por placa
- Resúmenes de fondos por año
- Registro de retiros con opción de adjuntos
- Cargue masivo de datos (nuevos periodos)
- Gestión de usuarios, roles y permisos
- Dashboard con métricas
